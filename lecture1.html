Lecture 1: Course Introduction and Web Basics

Summary

This lecture introduces the course and explains the difference between the Internet and the Web. It covers how a browser and a server communicate, and the types of web applications.

Topics Covered

  • Course introduction, CLOs and grading policy
  • Internet vs Web
  • Client-server request-response model
  • URL/URI, HTTP/HTTPS, DNS, hosting
  • Web standards: W3C, WHATWG, ECMA, IETF
  • Static, dynamic, MPA, SPA, PWA
