Lecture 1: Course Introduction and Web Basics

How the internet and the web work

Summary

This lecture introduces the course, its learning outcomes (CLOs) and the assessment plan. It explains the difference between the Internet and the Web, how a browser and a server communicate, the key web terminologies, web standards, and the types of web applications.

Course Introduction

CLOs (Course Learning Outcomes)

CLOs describe what a student should be able to do after completing the course, for example developing a professional front-end using client-side technologies.

Assessment Plan and Grading Policy

Marks are divided between assignments, quizzes, mid-term and final exam. The grading policy tells how these marks convert into the final grade.

Client-Server Request-Response Model

The client (browser) sends a request to the server. The server finds the page and sends back a response, which the browser displays.

  • Step 1: User types a URL in the browser.
  • Step 2: Browser sends an HTTP request to the web server.
  • Step 3: Server processes it and sends a response (HTML, CSS, JS).
  • Step 4: Browser shows the page.

Core Terminologies

URL / URI

URI identifies a resource. URL is a URI that also tells where to find it, for example https://www.example.com/index.html.

HTTP / HTTPS

HTTP is the protocol used to transfer web pages. HTTPS is the secure version that encrypts the data.

DNS

Domain Name System converts a domain name (example.com) into an IP address, like a phone book for websites.

Hosting

Hosting is the service that stores a website's files on a server so that it is available on the Internet.

Web Server and Browser

A web server stores and delivers web pages. A browser (Chrome, Edge, Firefox) requests and displays them.

Web Standards and Bodies

  • W3C: sets standards for HTML and CSS.
  • WHATWG: maintains the HTML living standard.
  • ECMA: standardizes JavaScript (ECMAScript).
  • IETF: develops internet protocols like HTTP.
