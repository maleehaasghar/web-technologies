Lecture 6: CSS Box Model

Spacing, borders and sizing

Summary

This lecture explains that every HTML element is a rectangular box made of content, padding, border and margin. It also covers margin collapsing, box-sizing, size limits, overflow, the display property, and borders, shadows and spacing techniques.

The Box Model

  • Content: the text or image itself.
  • Padding: space between content and border (inside).
  • Border: line around the padding.
  • Margin: space outside the border, between elements.

Margin Collapsing

When the vertical margins of two elements touch, they do not add up. The larger margin is used instead.

Size Constraints and Overflow

  • width / height: size of the content box.
  • min-width / max-width: smallest and largest allowed width.
  • overflow: what happens when content is bigger than the box: visible, hidden, scroll or auto.
