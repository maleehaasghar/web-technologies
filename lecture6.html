Lecture 6: CSS Box Model

Summary

This lecture explains that every element is a box made of content, padding, border and margin. It also covers box-sizing, overflow and the display property.

Topics Covered

  • Content, padding, border and margin
  • Margin collapsing
  • box-sizing: content-box vs border-box
  • width, height, min/max and overflow
  • display: block, inline, inline-block, none
  • Borders, shadows and spacing techniques
