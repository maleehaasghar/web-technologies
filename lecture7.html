Lecture 7: CSS Positioning and Stacking

Summary

This lecture explains how elements are placed on a page using different position values. It also covers z-index for stacking and floats with common layout problems.

Topics Covered

  • Normal document flow and static positioning
  • relative, absolute, fixed and sticky positioning
  • Offset properties and the containing block
  • z-index and stacking contexts
  • Floats, clearing and common layout pitfalls
