Lecture 3: HTML Document Structure and Elements

The building blocks of a web page

Summary

This lecture covers the role of markup and the structure of an HTML document. It explains elements, tags, attributes, nesting and validation, then headings, paragraphs, text formatting, hyperlinks, images, media, lists and tables, and finally the new elements and features of HTML5 with browser support.

Role of Markup

HTML (HyperText Markup Language) is the most basic building block of the Web. It defines the meaning and structure of web content. The "hyper" in hypertext refers to hyperlinks, where you click on text or an image to jump to another web page.

  • A markup language "marks up" a document by surrounding parts of its content with tags.
  • Tags are enclosed in angle brackets (< >) and usually come in pairs (opening and closing).
  • Markup is not a programming language. It does not run logic or math, it only tells the browser what the content is.

HTML Document Structure

A web page has a predictable structure:

  • DOCTYPE: tells the browser it is an HTML5 document.
  • head: information about the page (title, meta tags, CSS links).
  • body: everything that is visible on the page.

The browser builds a Document Object Model (DOM), a tree of all the elements of the page.

Nesting

HTML elements form a tree. Close elements in reverse order: the last opened is the first closed.

Correct nesting: <p><strong>Important</strong></p>

Wrong nesting: <p><strong>Important</p></strong>

HTML Document Validation

An HTML validator is a tool that checks the syntax of HTML documents and makes sure they follow W3C standards. Tools: W3C Markup Validator and Nu HTML Checker.

Importance of Validation

  • Ensures the code works across browsers.
  • Finds errors so they can be fixed early.
  • Gives accessibility compliance (important for users with disabilities).
  • Guarantees proper structure and better SEO ranking.

How to Use a Validator

  1. Visit a tool like the W3C Validator (validator.w3.org).
  2. Upload your HTML file or paste your code.
  3. The tool highlights errors and suggests corrections, for example missing closing tags or invalid attributes.

Headings and Paragraphs

Headings <h1> to <h6> create a content hierarchy. Paragraphs use <p>.

Best practice: use h1 to h6 to describe hierarchy, and use CSS to make text look larger or smaller.

Images

An image needs a source and a description: <img src="student.jpg" alt="Student studying" width="400">

  • src: where the image comes from.
  • alt: text alternative for accessibility.
  • width: display width.

Media (Audio and Video)

HTML5 plays audio and video without third-party plugins like Flash.

  • <audio controls> with a <source src="lecture.mp3" type="audio/mpeg">
  • <video controls width="480"> with a <source src="demo.mp4" type="video/mp4">

Captions and transcripts make teaching media more inclusive.

Lists

  • ul: unordered list (bullets)
  • ol: ordered list (numbers)
  • li: list item
  • Description list: <dl> holds terms <dt> and their definitions <dd>, used for a glossary or dictionary.

Tables

Tables are for data with relationships: <table>, <tr> (row), <th> (heading cell) and <td> (data cell).

Regions of a Professional Table

  • caption: what the table is about.
  • thead: column or row headers.
  • tbody: the main data.
  • tfoot: summary or totals.

Table Attributes

  • border: adds a border around the table and cells.
  • cellpadding: space inside the cells.
  • cellspacing: space between the cells.

Colspan vs Rowspan

colspan merges cells across columns and rowspan merges cells across rows.

Do not use tables just to create page layout. Use CSS layout for that.

HTML5: New Elements, Attributes and Browser Support

Key Features of HTML5

  • Responsive design: the layout adjusts to the screen size.
  • Viewport meta tag: makes the website scale correctly on different screens.
  • Flexible multimedia: native video and audio.
  • Cross-platform compatibility: features like <canvas> work on many devices.
  • Forms and input types: new types like email, tel and date. A tel input brings up a numeric keypad on a smartphone.
  • Offline support: localStorage and service workers let web apps work without internet.

The canvas Element

Used for drawing graphics, animations or games using JavaScript. It supports 2D, and 3D through WebGL.

HTML5 Storage Options

  • localStorage: stores data with no expiration date.
  • sessionStorage: stores data for the session duration.

Browser Compatibility and Support

HTML5 is widely supported in modern browsers. Semantic elements, audio, video and canvas work across Chrome, Firefox, Safari and Edge.
