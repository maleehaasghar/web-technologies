Lecture 3: HTML Document Structure and Elements

Summary

This lecture covers the structure of an HTML document, including elements, tags and attributes. It also covers text, links, images, tables, lists and new HTML5 features.

Topics Covered

  • Role of markup
  • DOCTYPE, head, body
  • Elements, tags, attributes, nesting
  • Headings, paragraphs, text formatting
  • Hyperlinks: absolute vs relative
  • Images, media, tables and lists
  • HTML5 new elements and browser support
