Lecture 8: CSS3 Features

Summary

This lecture covers modern CSS3 features like rounded corners, gradients, shadows, transforms and animations. It also introduces web fonts, CSS variables and media queries.

Topics Covered

  • Rounded corners, gradients, shadows and opacity
  • 2D/3D transforms
  • Transitions and keyframe animations
  • Web fonts and icon fonts
  • CSS custom properties (variables)
  • Media and feature queries
  • Vendor prefixes and cross-browser compatibility
