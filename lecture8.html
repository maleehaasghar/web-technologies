Lecture 8: CSS3 Features

Modern effects and animations

Summary

This lecture covers modern CSS3 features: rounded corners, gradients, shadows and opacity, 2D/3D transforms, transitions and keyframe animations, web fonts and icon fonts, CSS custom properties (variables), media and feature queries, and vendor prefixes for cross-browser compatibility.

Rounded Corners, Gradients, Shadows and Opacity

  • border-radius: makes corners round.
  • linear-gradient(): smooth mix of two or more colours.
  • box-shadow: shadow around a box (x, y, blur, colour).
  • opacity: transparency from 0 (invisible) to 1 (solid).

2D / 3D Transforms

The transform property changes an element without affecting the layout: translate (move), rotate, scale (resize) and skew (tilt). 3D transforms add depth with rotateX, rotateY and perspective.

Web Fonts, Icon Fonts and CSS Variables

  • Web fonts: fonts loaded from the internet using @font-face or Google Fonts.
  • Icon fonts: icons that behave like text, so they can be resized and coloured with CSS.
  • Custom properties (variables): defined as --name: value and used as var(--name).

Media and Feature Queries

@media applies CSS only when a condition is true, such as a screen width below 600px. @supports (feature query) applies CSS only if the browser supports a feature.

Vendor Prefixes and Cross-browser Compatibility

Browsers used prefixes for new features: -webkit- (Chrome, Safari), -moz- (Firefox) and -ms- (old Edge). They helped new properties work in all browsers, and testing in different browsers is still important.
