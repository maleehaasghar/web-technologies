Lecture 5: CSS Syntax and Selectors

Summary

This lecture introduces CSS syntax and the three ways to add CSS. It covers selectors, pseudo-classes, the cascade, specificity and basic text and color properties.

Topics Covered

  • CSS syntax
  • Inline, internal and external style sheets
  • Selectors: element, class, id, attribute, grouping, descendant
  • Pseudo-classes and pseudo-elements
  • Cascade, specificity and inheritance
  • Colour, font, text and background properties
