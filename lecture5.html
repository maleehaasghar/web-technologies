Lecture 5: CSS Syntax and Selectors

Styling and choosing elements

Summary

This lecture introduces CSS syntax and the three ways to add CSS. It covers selectors, pseudo-classes and pseudo-elements, how the cascade, specificity and inheritance decide which rule is applied, and the basic colour, font, text and background properties.

CSS Syntax

A CSS rule has a selector and a declaration block. Each declaration is a property: value; pair.

p { color: red; font-size: 18px; }

Inline, Internal and External Style Sheets

TypeWhereUse
Inlinestyle attribute inside a tagOne single element
Internalstyle tag in the headOne single page
Externalseparate .css file linked with link tagMany pages (best practice)

Selectors

  • Element: p, h1 (all such tags)
  • Class: .note (many elements)
  • Id: #title (one element)
  • Attribute: input[type="text"]
  • Grouping: h4, h5 (same style for both)
  • Descendant: .box p (p inside .box)

Pseudo-classes and Pseudo-elements

  • Pseudo-class styles a state, e.g. :hover.
  • Pseudo-element styles a part of an element, e.g. ::first-letter.

Cascade, Specificity and Inheritance

  • Cascade: when rules conflict, the later one wins.
  • Specificity: id is stronger than class, class is stronger than element.
  • Inheritance: some properties (like color and font) pass from parent to child.
